The Perl and Raku Foundation (TPRF) is grateful to announce a gift of **$12,000
from NVIDIA** in support of Perl and CPAN. Contributions like this one let us
keep maintaining the Perl 5 core and support our mission of keeping critical
infrastructure alive.

When you think of NVIDIA, you may think of GPUs and LLMs, so let's highlight a
few related projects with ties to the Perl and Raku communities.

Superpowers
-----------

The first project that springs to mind is Jesse Vincent's [Superpowers](https://github.com/obra/superpowers).

> Superpowers is a complete software development methodology for your coding agents, built on top of a set of composable skills and some initial instructions that make sure your agent uses them.

While this is not written in Perl or Raku, [Jesse](https://metacpan.org/author/JESSE) was the Perl pumpking for versions 5.12 and 5.14 of the language. As [his Wikipedia entry](https://en.wikipedia.org/wiki/Jesse_Vincent) notes:

> He changed the release cycle for Perl 5 from an irregular release done at the
> leisure of the project manager to a regular timeboxed release with
> development releases monthly and stable releases annually.

So the annual stable release cycle we now take for granted is largely thanks to
Jesse's work.

PAAD
----

[Ovid](https://metacpan.org/author/OVID) has been working on [PAAD](https://github.com/ovid/paad).

> PAAD (rhymes with "pad") is a set of skills for AI coding assistants. It reviews what the AI is about to work on — the spec, the plan, the architecture, the code — while you can still change it. That's Pushback, Alignment, Architecture, plus the Discipline to actually run them.

Among other things, Ovid is the author of [*Beginning
Perl*](https://www.amazon.com/Beginning-Perl-Curtis-Poe/dp/1118013840/). You
can read more about Ovid in [this perl.com interview by Mohammad Sajid
Anwar](/article/the-perl-ambassador-curtis-poe/).

skilletor
---------

[Getty](https://metacpan.org/author/GETTY) has been working on [skilletor](https://github.com/Getty/skilletor):

> skilletor is a Claude Code and Codex plugin plus a standalone CLI. It installs skills, agents and rules from configured sources and keeps them up to date: it reconciles at session start, re-checks (throttled) during the session, pulls anything new, and tells the model what changed. Want shared skills? This is most likely the tool.

Getty has many Perl projects on the go, one of the more ambitious being
[DBIO](https://metacpan.org/pod/DBIO), a native relational mapper built on DBI
and a modern successor to [DBIx::Class](https://metacpan.org/pod/DBIx::Class).

He also maintains [Langertha](https://metacpan.org/pod/Langertha):

> Langertha provides a unified Perl interface for interacting with various Large Language Model (LLM) APIs. It abstracts away provider-specific differences, giving you a consistent API whether you're using OpenAI, Anthropic Claude, Ollama, Groq, Mistral, or other providers.

Hopefully you'll find some inspiration above, if LLMs are part of your toolkit.

Thank you, NVIDIA
-----------------

Once again, we'd like to thank NVIDIA for supporting Perl and CPAN. If your
organization relies on these ecosystems, you can [support
TPRF](https://www.perlfoundation.org/donate.html) or budget engineering time
for the shared infrastructure you already depend on.
